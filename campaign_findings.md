# Agent Tank Submission Findings

## Official source

Submission form: https://portal.genlayer.foundation/agent-tank/hackathon/submit/

## Verified rules and schedule

The form states that each builder submits one project and that the application must include the full project application plus a public GitHub repository. The repository must belong to the linked GitHub account. Submissions are editable until the tank closes. The displayed schedule is Sep 3 to Sep 17 at 15:30 UTC, with accepted projects published to the Project Explorer.

## Track options

The form exposes these tracks: Agentic Commerce Infrastructure; Onchain Justice; Prediction Markets & Real-World Settlement; AI Governance; Future of Work; Autonomous Protocols.

For FlowBond, the strongest primary track is Future of Work because the campaign description emphasizes work verified by consensus and payment tied to outcomes. Autonomous Protocols is a secondary fit because FlowBond is designed as an agent-to-agent coordination and settlement rail.

## Important scope rule

The submission must present FlowBond as a distinct project. The MilestoneJury repository and its deployment evidence must not be used as the FlowBond implementation or proof. FlowBond is currently a live frontend prototype with a prototype Agreement Builder and no live fund movement; those limits must be stated plainly.
